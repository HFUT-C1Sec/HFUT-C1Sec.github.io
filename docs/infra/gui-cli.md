---
title: "GUI 与 CLI"
---

- GUI（Graphical User Interface）：图形用户界面。就是你平时用的窗口、按钮、菜单，靠鼠标点点击操作。Windows桌面、浏览器，都是GUI。方便、直观。
- CLI（Command-Line Interface）：命令行界面。一般是以一个黑框展现敲命令操作。终端、PowerShell、CMD，都属于CLI。

教你如何化身嘉豪：按下 win+R，输入cmd启动命令行。输入 color a ，将字体颜色改为荧光绿，再输入 dir /s，或者 tree。按下ctrl+c停止。

GUI的优势是直观、易上手，适合浏览、编辑、配置。

在网络安全内，要开始习惯使用CLI界面，主要有以下原因：

1. 大部分安全工具只有CLI界面，没有GUI界面使用。纵使有，如Nmap的GUI版本Zenmap，点击也不如输入指令快
2. CLI界面执行实现功能更加快捷，例如：若在D盘的每个文件夹内创建一个README.md文档，使用GUI手都可能点废了。
3. 在渗透测试中，往往没有GUI给你使用：上传webshell实现了命令执行，但必须通过CLI交互。大部分服务器都没有显示界面，连远程桌面连接的机会都没有。这些都要求我们必须使用CLI完成任务。
4. 图形化界面传输数据量大，网络差时容易卡死或断开。CLI只传文本指令和输出，数据量小，在网络不稳定的情况下依然能正常工作。

速速了解CMD，BASH的使用。熟悉Linux Bash的相关指令。在你熟悉之后，会发现这些內容其实并没有想象中吓人，影视中的“黑客”，没有那么玄幻。
