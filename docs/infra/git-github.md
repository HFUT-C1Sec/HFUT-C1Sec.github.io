## Git

Git 是一款惊人的版本控制工具。

- Git的主要功能为备份与回滚。简单讲，Git是时光机。假设读者记录了不同时间点的存档（就像游戏那样），此时读者正在对文件做改动，如开发与测试。这些操作可能导致代码bug无法修复，环境崩溃等问题，而解决这些问题令人焦头烂额。于是你可以选择直接恢复至上个存档，一切均当无事发生，而该操作就称作回滚。

- 除了备份与回滚外，另外的功能Branch分支，更是新颖且灵巧的设计。至于具体功能如何，读者在认识计算机世界的过程中会逐渐了解。

虽然Git提供了图形化操作界面，但命令行操作界面依然是主流用法。初次接触Git会让人感到十分不适，但请坚持，这在未来的开发生涯中会用得到的。

## GitHub

GitHub是代码托管平台，后被微软收购。开发者、安全人员会将自己的代码或者payload存放在GitHub上云端存储，防止丢失。

- 如果你仅仅希望利用GitHub作为代码的网盘，那么可以将代码仓库设为私有（Private）。

- 如果你希望将自己的代码公开，可以将代码仓库设置为公开（Public）。若你的作品优秀，其他人看到了可以为你点star表示收藏，审阅你的代码，发现bug，向你提出issue指明修整思路，或直接提交request亲自帮你优化代码。

- 同样的，你也会在这里发现许多小众或并不小众的软件、脚本、插件、电子书，如Mactype、Clash、V2ray、《提问的智慧》、《Github漫游指南》。大部分CLI安全工具都在GitHub上存有开源代码。

- 若你感兴趣，也可以自行了解有关于互联网开源精神的相关內容。

- 关于GitHub的梗：由于从事IT行业的男性占比远远高于女性，因此GitHub也被戏称为全球最大的同性交友平台。



Git的备份功能针对本地备份，而如果想要联动Git和Github使用，也非常简单。

- 如果你想要做到利用Github云端备份，使用Git的一系列指令，就能实现无痛从本地上传代码至Github。

- 同样地，如果你想要从Github下载一个內容，使用Git的 git clone <URL> 指令，也可以无痛拉取你想要的內容，而不是亲自到Github上看着图形界面手动翻找。

学习Git、Github尽管在开始或很长一段时间，这段时间可能长达几年，都不会频繁使用。但只要在IT行业，至少Github是一个绕不开的平台
