## 什么是环境？

环境就是你运行某个程序或代码时，所依赖的基础。我们可以举出几个生活中的例子让你感受“环境”的存在：

- 若你玩过MC会清楚，PC端MC分为Java版与基岩版，安装Java版时，程序会要求你下载 JRE/JDK，称作Java运行时环境。缺少了这个，或者安装的Java版本错误，都会导致游戏无法正常运行。
- 4399网页小游戏是大家年少时经常游玩的网站。但现在再访问，很多游戏都无法正常打开。原因是现代浏览器不默认安装Flash，而4399小游戏又基本都是Flash编写的。缺少了这种环境，游戏就无法正常启动。
- 随着Windows操作系统演进到win11，很多针对win10和win7的內容与程序都停止更新。如果你在win10系统上下载一个声明只支持win11或更新版本的软件，运行时软件会提示“此程序与当前操作系统不兼容”

也就是说，程序运行受制于一些前置条件，他们存在于计算机上，你平时看不见，但缺少它们会导致程序崩溃。这些条件，就是广义的环境，一种抽象的概念。而后续我们谈论的环境，主要针对计算机本身，如解释器，编译器，操作系统等配置，相对狭义。

## 虚拟机

你可以观察到，环境的版本不断更新，而偏偏程序运行又与环境强行捆绑。那么复杂的环境问题会逐渐显现：

1. 为什么你的代码在我这跑不起来啊：A与B安装了不同版本的Python解释器，不同版本的Python语法具有差异。A编写了一个基于高版本Python语法的脚本文件，并发送给B。B计算机上的Python解释器版本很低，无法解释只属于高版本的Python语法，执行文件就会发现运行失败。
2. 环境又炸了：有时我们会尝试复现一些Payload，漏洞，而这些漏洞的依赖环境不同，假设漏洞A依赖于PHP x.xx，而漏洞B依赖于PHP y.yy，有的人会投机取巧，在电脑上安装两个版本PHP的解释器。这可能导致以下问题：
   - 这些不同版本的解释器都加载进入了环境变量，导致每次运行，系统会自动调用最先加入的那个。于是有的漏洞能够验证，有的不能。
   - 不是每个人都对自己的电脑了如指掌，可能在某一天使用者移动了自己的解释器文件路径，而环境变量中的內容没有更改。在执行程序时，系统依然去原来的位置寻找解释器，但找不到，就会又招致报错。

环境引起的问题往往非常隐蔽，尽管环境问题可以被追踪，可显然一直花费时间在追踪环境问题上是相当浪费精力与生命的。一种解决方案是使用虚拟环境。而我们引出另外一种更加傻瓜的方法：使用虚拟机。并且使用虚拟机的理由不止这一个。

简单些来理解，通过某种虚拟化手段，可以在一台计算机上同时运行多个操作系统。主流使用的虚拟机软件是 VMware，这是我们需要先安装的。通过镜像，预安装虚拟机等方式，可以在电脑上运行多个系统。

使用虚拟机的理由很多：

1. 开发环境稳定：我们可以开启一个Windows虚拟机，上面专门安装某个版本的解释器或编译器环境。对应版本的开发和研究就在这一台虚拟机上完成，省去折腾。如果不小心把环境玩坏了，虚拟机有特殊的“快照”功能，可以对计算机状态快速回档。
2. 满足对不同的操作系统使用需要：大多数PC上运行的都是Windows操作系统，而如果想要体验GNU/Linux系统，通过Vmware就可以完成。使用如 Ubuntu、Fedora、Suse、Kali、Parrot、CentOS等系统。同样的，其他系统如MacOS、鸿蒙OS，虽然闭源操作系统需要一定方法破开锁，也可以在虚拟机中跑起来。
3. 工具集成：渗透测试（红队）和安全响应（蓝队）都会用到大量工具。这些工具有的依赖Windows，有的依赖Linux。如果全装进宿主机，不仅容易让系统变乱，还可能再度引发环境冲突。因此常见的做法是：把常用工具统一装进一台虚拟机，整理、调试、快照，形成一套固定的工具环境。以后干活的机器就是它，干净、稳定、顺手。

接下来你需要做的是：安装VMware，然后找一份别人做好的预安装虚拟机来试试。

在B站、YouTube、CSDN、知乎上都有大量教程，找到他们的教学视频或帖子，跟着指导完成。过程出现意外则先问AI，直到AI实在搞不定了，该动身问身边的真人了。

## Kali-GNU/Linux

上述提到了虚拟机的优点之一是工具集成。一般来说我们至少要拥有两台熟悉的虚拟机，一台Windows，一台GNU/Linux。而做渗透测试最常使用的就是Kali-GNU/Linux。

Kali-GNU/Linux 是由OffSec公司推出的一款开源免费安全类工作专用Linux发行版，特点包含：

1. 释放了极大操作权限，使用自由，资源占用率低，运行丝滑。
2. 塞入了绝大多数渗透测试使用的攻击性工具，部分非攻击性分析工具也有，如wireshark。使用Kali至少能给我们省下配置GNU/Linux的时间。
3. 对于非默认安装的內容，可以使用包管理器apt，或者 git clone 安装，十分方便

Kali受到广泛使用，与Vmware同样可以在各个平台搜索到安装和使用教程。
