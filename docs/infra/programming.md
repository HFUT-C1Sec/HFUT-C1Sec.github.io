Python和PHP会陪伴红队技术学习相当长的一段时间。事实上可能多长呢，长到可能你找到第一份实习甚至工作或者你坚持不下去转行了。

## 先从Python开始

编程语言的学习先从Python开始。

这里对于编程的要求并不高，不需要独立写出项目、工具，不需要独立写出完整脚本。在接触红队技术的前期，手撕脚本的编程能力不是刚需。

真实对Python编程的要求是：懂得基本语法，能看懂一个PoC脚本的功能。可以自己更改脚本中的IP、端口、文件路径这类参数。这种程度的能力就已经足够支撑很长一段时间了。

如果你有能力自己写，那肯定是加分项。

## PHP

PHP目前仍然是网站的主流后端语言。学习红队技术时，经常需要和PHP构建的Web设施打交道——Web界面、Web服务器、上传Webshell，都绕不开PHP。所以PHP也是基础技能之一。

对PHP的要求和Python类似：能看懂语法，能改参数即可。

不需要往开发方向走，红队不需要学如何用PHP搭建网站。

## 千万不能是C++

尽管Python是公认最推荐的入门编程语言，但受制于现实，我们接触的第一门语言可能各不相同。可至少千万别是C++：

1. C++语言本身本身难：指针、内存管理、模板使用困难，特性极多。
2. 前期完全用不上：红队入门接触內容是HTTP、SQL、PHP，至多涉及PHP，JS，JSP，完全和C++无关。而C与C++是二进制逆向分析时才需要了解的內容，那时至少是一年以后，并且还用C居多。C++是一门开发用的语言。
3. 毁母语：C++的编程思考逻辑和处理，会影响之后的编程习惯。养成糟糕的习惯在后续会很难改正。

C++不是不能学，但绝对不是现在。 暂时晾在一边并不会影响你继续前进。这可能是为数不多出现了强烈偏见的部分，但思考后并不决定更改。
