---
title: "奥卡姆剃刀（Occam's Razor）"
---

打破常规思维有助于我们跨越想象的界限，从而接触到最初我们无法识别的可能性和选项。因此，我们会遇到许多选项，解决问题的整个过程会很快变得非常复杂。奥卡姆剃刀原则有助于简化这些情况。

奥卡姆剃刀是现代科学理论的核心原则之一。该原则基于以下定义：

对于同一事实的多种充分解释，最直接的理论优于所有其他理论。换句话说：最简单的解释总是最有可能的。

例如，我们可以假设我们的电脑停止工作了。我们已经可以想象到，这可能有很多原因。可能是电源故障、CPU 问题，甚至可能是主板烧毁了。

在遇到此类或类似问题时，我们会在开始解决问题之前，自动地列出可能的原因。许多人采用排除法工作。他们会排除那些可能导致问题的可能性。这种方法已经把我们引向了错误的方向，并导致解决问题需要花费大量精力。采用这种方法，大多数人会首先拆开他们的电脑，检查所有连接。他们在寻找最可能的原因，但忽略了简单性因素。

毕竟，我们应该问的问题是：

为什么我们的电脑没有通电？

当我们问这个问题时，我们的脑海中会自动形成与"电"这个词相关的联想。在这种方法中，第一个想法通常集中在电源上。电源为电脑调节电力。因此，大多数人的第一反应是电源有缺陷，无法正常工作。

然而，当我们想到"电"时，我们不要忘记打破常规思维。因为如果我们给自己设限，认为问题只能出在我们的电脑上，我们就会极大地限制我们的选择。如果我们抛开这些限制，从电脑往外看，第一个接触点就是连接的插座和多孔插排。如果我们遵循这种方法，我们就会发现我们的多孔插排开关被关掉了；因此，电脑没有电力来启动。

所以，在这种情况下，最直接的解释也是最有可能的。

奥卡姆剃刀的实践应用

奥卡姆剃刀在理论上听起来比在实践中要容易。我们可以说最简单的解释是最有可能的。然而，事实是，除此之外，情况并非总是如此。我们还必须区分单个细节、机制与整体概念。在我们的学习阶段（因此也包括我们对公司进行渗透测试 (penetration tests) 的过程中），我们会遇到许多学习新知识的情况。然而，关键是要理解整体概念，而不是所涉及的单个步骤。例如，一旦我们熟悉了 SQL 注入 (SQL injection) 及其发生方式，我们可能一开始会觉得单个步骤很困难。然而，一旦我们理解了整体概念，我们就能很容易地发现一个 Web 应用程序何时容易受到 SQL 注入攻击。

如果我们已经处理过 SQL 注入，并且知道它们可能是什么样子，我们也会理解检测和利用它们的单个步骤可能非常复杂。然而，保持不变的是概念本身。在学习新主题时，概念是主要焦点。

另一个例子是进行渗透测试的方法，这在整个网络安全 (cybersecurity) 社区中非常普遍。每个人都在讨论可能发生的案例以及如何最好地处理它们。让我们回想一下奥卡姆剃刀原则，并打破常规思维。

任何做过至少两三次渗透测试的人都会发现，每一次都是独一无二的。即使客户端和服务器使用相同的系统，它们的配置通常也是独特的。渗透测试中的各个阶段是其独特之处，我们可以在渗透测试流程模块中了解更多相关信息。

关于渗透测试最佳方法的最简单解释是，我们利用我们能获得的信息进行工作。

我们如何获取和使用这些信息的独特技术，同样只是所遵循的单个步骤，而不是整个概念。这同样适用于大多数漏洞利用攻击 (exploitation attacks) 及其各个步骤。一旦我们理解了整体情况，适应给定的情况和条件就会容易得多。然而，如果我们只学习了单个步骤，我们将很难将它们应用于新情况，因为我们不了解它们对系统及其应用程序的影响。

在后续过程中，我们会一次又一次地看到这种现象。一旦我们确定了问题的解决方案，实现它的过程和所需步骤在大多数情况下似乎都相当直接。回过头来看，一旦我们知道了解决方案，事情似乎总是很简单。毕竟，艺术不在于拿到某个 flag，而在于找到通往它的道路。
