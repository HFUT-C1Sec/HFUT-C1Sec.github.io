## 放下对系统课的执念

"系统性学习"的吸引力在于：一套课程似乎承诺从 0 到精通，跟着走就行。但在网络安全这类方向上不太走得通：知识树太大，没有一张路线图能覆盖所有细节；完全系统化容易掉进"打不完的基础"；碎片积累是常态，零散内容攒到一定程度，对整体的感觉才会出现，而新漏洞新技术一直在出，往往没有现成的系统课。

所以不必执着于"先找到完整路线再开始"，更实际的做法是针对问题查资料，需要哪块补哪块，在实践中学习。

## 保留方向感

不追求完全系统，不等于乱学。方向感来自一个问题：**我所在的专业，真正要用到的核心技能是什么？**

想清楚这个问题，可以把关系较远的内容先放一放。很多学生觉得专业"什么都学、很杂"，拆开看：课程里有高数、线代、思政、英语、密码学、专业导论；技能里有 Office、单片机、电路设计、算法、各种编程语言。以网络安全为例，主线大致是找到漏洞、找到可用凭证、完成渗透，对照这条主线，上面有些内容较远，有些则是绕不开的基础。

不同专业都有朴素、枯燥、但必须练的基础技能：自动化是 PLC 能写能调；电信是画板子、焊板子，VHDL/FPGA 能跑通；计科是写代码、调 bug、配环境、项目能跑起来。网络安全也一样：Web 渗透、提权、漏洞挖掘、应急响应。碎片积累到一定程度，会慢慢看出专业的"专"在哪里——区分你的，往往就是这些基础。
