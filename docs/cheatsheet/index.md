# 知识点合集速查表

> **整理与作者：catchcat**

本栏目是 C1SEC 汇总的网络安全知识点速查合集，把常用攻防技术按主题拆成一篇篇可以随查随用的速查文档，
并配套三张可视化知识图谱。全部内容共 **58 篇速查文档 + 3 张知识图谱**。

文档按学习的推进顺序编号（`01` → `58`），建议顺着编号读；需要临时查某个点时，直接按左侧目录跳转即可。

## 每篇文档的结构

速查文档统一按「原理 → 检测 → 利用 → 防御 → 检查清单」组织，篇幅控制在一屏到两屏之间，方便在打靶、
做 SRC 或复盘时随手翻。文中的 `[[]]` 双链已转换为站内链接，可以直接在相关主题之间跳转。

## 内容分布

| 分组 | 覆盖内容 |
|:---|:---|
| **基础入门**（7 篇） | Web 与协议基础、编码与古典密码、Linux / Windows 渗透、工具链、信息收集、脚本化 |
| **Web 漏洞 · 注入类**（13 篇） | OWASP Top 10 总览与注入类专题：SQL / NoSQL / 命令注入、XSS、前端、文件上传与包含、SSRF、XXE、SSTI、反序列化、中间件与数据库、WAF 绕过 |
| **OWASP 分类速查**（8 篇） | OWASP 2021 其余分类的逐条速查：A01、A02、A04 – A09 |
| **密码学**（3 篇） | AES 与哈希、RSA、密码学攻击与哈希传递 |
| **内网与云原生**（6 篇） | 内网与域渗透、代理与隧道、云原生（Docker / Kubernetes）、供应链 |
| **审计 · 逆向 · 二进制**（7 篇） | 代码审计、PWN、逆向与算法还原、隐写、取证、恶意文档分析 |
| **跨域与新兴方向**（7 篇） | 移动端、IoT 与嵌入式、工控 ICS/SCADA、邮件、社会工程、AI Agent 与 AI 辅助 |
| **实战与复盘**（7 篇） | SRC 实战报告与 CTF Writeup 方法论 |
