# 🤖 AI 辅助 CTF 全技巧

> 差异化招牌课（3.2d）：如何用 LLM 辅助 CTF——知识检索、payload 生成、思路验证。核心命题：AI 放大的是你的判断力，不是替代你的判断力。

---

## 一、🟢 AI 在 CTF 里的四个正确用法

### 1.1 知识检索（最稳）
```text
场景：忘了某个伪协议语法 / 某 CMS 的已知 CVE / 某算法的参数
用法：问 LLM「php://filter 读源码的标准写法」「ThinkPHP5 rce poc」
价值：替代搜索引擎的 3-5 分钟 → 10 秒；知识密度高且可追问
注意：新 CVE / 小众框架 → LLM 可能编造，必须交叉验证
```

### 1.2 脚本生成与修补
```text
场景：盲注脚本模板、RSA 解密骨架、图片宽高爆破
正确姿势：自己会写骨架 → 让 AI 补细节/查 bug
反例：完全不会写让 AI 从零生成 → 出错时你改不了（能力配不上工具）
```

### 1.3 思路brainstorm（卡题时）
```text
「这题给了 db 文件 + 一张损坏 png，可能的方向？」
AI 给清单：SQLite 恢复 / 文件拼接 / 隐写组合……
人负责：判断哪个方向跟题目提示匹配
```

### 1.4 模型专项（自研端侧模型演示）
```text
XuanmuSec-2.6B（ModelScope 开源）：CTF 专用微调
  · 知识注入（CPT）+ 行为训练（SFT）：能结构化输出解题分析
  · 配合 intelpwn：一键完成 pwn 入门题「反汇编→注释→漏洞识别→exp→验证」
课堂用法：演示「AI 能做什么」→ 拆解内部流程 → 讲清边界
```

## 二、🟡 实战工作流（把 AI 嵌进解题流程）

```text
读题 → 1) 知识盲区先问 AI（协议/算法/框架）
     2) 侦察结果丢给 AI 汇总归纳
     3) 确定方向 → payload/脚本让 AI 起草，人工验证
     4) 卡住 → 贴所有已知信息让 AI brainstorm
     5) 拿 flag → 让 AI 帮写 writeup 初稿

原则：AI 出草案，人做验证——每个 AI 输出都要跑过/查过才算数
```

## 三、🟢 边界：AI 代替不了什么（这部分比用法更重要）

| AI 弱项 | 为什么 | 你的对策 |
|---|---|---|
| 动手验证 | LLM 只输出文本，不能跑 | 自己搭环境跑，结果才是证据 |
| 新题/创新题 | 训练数据没见过 → 幻觉 | 基础功扎实才能判断 AI 说的对不对 |
| 长链路推理 | 多步组合容易中途错 | 人主控思路，AI 只做单步 |
| 准确的记忆 | 版本/参数/细节常编造 | 关键信息查官方文档交叉验证 |

> 一句话：**AI 帮你「知道得更快」，帮不了你「判断得更好」**——判断力来自基础训练（这也是这门课存在的意义）。

## 四、🟡 prompt 模板速查

```text
知识检索：
「CTF 中 php://filter 读取 base64 源码的完整 URL 写法，附例子」

脚本起草：
「写 Python：对 http://x/?id=1 做 boolean 盲注，逐字符提取 database()，
 成功标志是页面含 'exists'，加 sleep 0.1 防封」

思路 brainstorm：
「CTF 题：附件一个 audio.wav 和一串 base64，解码后是乱码。
 已知 wav 频谱没有异常。列出 5 个可能的出题方向」

复盘：
「我思路卡在这：[描述]。最终解法是 [writeup]。帮我总结这次的知识盲区」
```

## 五、🔴 使用纪律（课程纪律声明）

```text
1. 比赛规则优先——禁止 AI 的比赛（如部分 AIA 类赛事）就别用
2. 学习期先手动 → 会了再上 AI（顺序反了 = 依赖工具失去基础）
3. AI 输出 = 假设不是答案 → 每条验证后再用
4. 敏感信息（未公开漏洞/内部目标）不要贴给云端 AI
```

## 🎓 上课流程卡（3.2d · AI 辅助 CTF · 120 分钟）

> 给讲师：本课是差异化招牌课，也是最容易上成"聊天课"的课。纪律：**演示环节占 60%，讲道理占 40%**——学员要的是亲眼看见，不是听趋势。现场演示全部提前录屏备份（网络/环境翻车时切录屏）。

**教学目标**：下课时学员能①正确把 AI 嵌进解题流程（四个用法）②说出 AI 的三个边界并演示一次幻觉翻车 ③现场用 XuanmuSec 和 intelpwn 各完成一次演示任务。

**课前准备**：
- XuanmuSec-2.6B 环境（Q4 量化 + llama.cpp/Ollama 起服务）+ 预载一道 Web 题
- intelpwn 环境 + 2 道 challenges 内置 pwn 题（提前跑通，确认当场能复现）
- 一个云端 LLM 会话窗口（ChatGPT/Claude/其他）开好
- **全部演示录屏**（翻车保险）

| 时间 | 环节 | 讲师动作 |
|---|---|---|
| 0-10 | 导入 | 现场对比：同一道 Web 题——Base 模型答非所问 vs XuanmuSec 结构化输出解题分析。话术："这是我们团队自己微调的端侧模型，今天教你们把 AI 用对地方" |
| 10-35 | 讲解 | §一 四个用法逐个配现场演示：知识检索（问伪协议语法）→ 脚本起草（盲注模板）→ 思路 brainstorm（贴题面要清单）→ 自研模型演示 |
| 35-50 | **翻车演示** | §三 边界：故意问一个 AI 会编造的问题（冷门 CVE 编号/不存在的函数），展示幻觉 → 教交叉验证。**这是本课最重要 15 分钟**——先立边界再教用法，学员才不会盲目依赖 |
| 50-95 | 实操 | 任务：①用 AI 检索补齐一个知识盲区并验证 ②让 AI 起草一段脚本并自己调试跑通 ③intelpwn 一键梭哈一道 pwn 入门题 → 然后**手动拆解它做了什么**（对照三级注释）④XuanmuSec 解一道题并评价它的分析哪里对哪里错。巡场重点：prompt 写得太模糊（教贴上下文）、把 AI 输出直接当答案不验证 |
| 95-115 | 讲解 | §二 实战工作流（五步嵌图）+ §四 纪律（比赛规则/先手动后 AI/敏感信息） |
| 115-120 | 收口 | 金句收尾："AI 放大判断力，不替代判断力——判断力就是这门课前面所有课时练出来的东西" + 作业：用 AI 辅助完整解一道题并写"AI 帮了什么/帮不了什么"复盘 |

**学员常见卡点（预判）**：
1. prompt 太模糊（"帮我做这道题"贴个图）→ 教信息喂法：题目原文+已知侦察+卡点，三段式
2. 把 AI 编造当真 → 每个实操任务强制要求"验证步骤"写进提交
3. 过度依赖（什么都要问 AI）→ 现场反例：基础检索 10 秒自己查完的，问 AI 反而慢
4. intelpwn 环境报错 → 备好录屏 + 预装好环境镜像

**被问倒的兜底**："AI 都这么强了还学 CTF 干嘛" → "工具梭哈的是入门题——能被自动化的知识就是这门课前半段教你打牢的地基；AI 解不了的新题，拼的正是你后半段要学的判断力。会用 AI 的前提是懂到能验证它"。
