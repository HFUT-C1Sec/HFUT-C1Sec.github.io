## Hello-CTF

[官网](https://hello-ctf.com/)

- 中文 CTF 入门教程与知识库，内容从 CTF 赛制、方向划分讲到常见题型。
- 覆盖 Web、Misc、Crypto、Reverse、Pwn 等 CTF 主要方向，包含基础概念、工具介绍、环境搭建和入门题思路。
- 以网站和电子书形式组织，查阅方便，适合建立 CTF 的整体认识。
- 内容偏文字教程，部分题目环境需要自己在本机或虚拟机中配置。

## Max极客君（B站）

[B站视频](https://www.bilibili.com/video/BV1eq4y1x71H/)

- B站 UP 主，发布网络安全和 CTF 相关视频。
- 内容偏 CTF 入门和 Web 方向，常见形式包括基础概念讲解、工具演示和题目分析。
- 视频可以作为文字教程的补充。

## BinaryAbyss（B站）

[B站视频](https://www.bilibili.com/video/BV1Fc411X7VX/)

- B站 UP 主，内容偏二进制、逆向和 Pwn 方向。
- 常见内容涉及汇编基础、程序调试、二进制漏洞和 CTF Pwn 题讲解。
- 需要一定的 C 语言、汇编和 Linux 基础，零基础直接看容易卡在工具和环境上。
