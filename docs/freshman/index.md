# 认知篇

大学和高中很不一样，这种不同渗透在生活学习的各个方面。该部分帮助学生理解自己要面对什么，需要如何调整。

!!! notes "注意"
这部分会相当有“爹味”，但学生可以自行选择是否阅读

涵盖內容有：

- 大学和中学的学习方式差别
- 怎么降低预期
- 怎么提问
- 怎么和他人相处

其中 [HTB《Learning Process》](../cognition/htb/){: target="\_blank" }
是HTB Academy的一个免费模组，用理性方式拆解了学习焦虑。是一本心态调整专用读物，适合焦虑时翻出来阅读
