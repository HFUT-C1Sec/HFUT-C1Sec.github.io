前置阅读材料：

- [HTB Academy-Linux Fundamentals 模组](https://academy.hackthebox.com/course/preview/linux-fundamentals)：了解常用命令，顺带了解 Linux，不求深入，只为补上命令基础

参考阅读材料：

- [OWASP-命令注入](https://community.owasp.org/attacks/Command_Injection)
- [OWASP WSTG - Command Injection](https://wstg.owasp.org/latest/11-Injection/11-Command_Injection/)
- [OWASP WSTG – Business Logic Data Validation](https://wstg.owasp.org/latest/14-Business_Logic/01-Business_Logic_Data_Validation/)

拓展材料：

- [ExplainShell](https://explainshell.com/)：复制一行命令，他会帮你解释 Shell 的所有参数（不过现在有了 AI，效果似乎没那么好了）
- [OverTheWire](https://overthewire.org/)：穿越网线，利用 bash 命令通关的战争游戏，可以了解 Linux 命令，内容量充实，可以玩很久

实验內容：

- Command Injection：命令注入/命令执行，5个实验
- Business Logic Vulnerabilities：业务逻辑漏洞：11个实验
- Information disclosure：信息泄露，5个实验

业务逻辑逻辑漏洞可以联系 week1 中的 Authenticaiton 思考
